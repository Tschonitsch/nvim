# nvim

My nvim config.

## Matugen

The colorscheme is generated by [Matugen](https://github.com/Tschonitsch/matugen) and written to `colors.lua`.

Colors are loaded by `lua/core/matugen.lua` and can be reloaded on the fly with `SIGUSR1`.

Some plugins, such as Bufferline, don't update their colors automatically, so Neovim still needs to be restarted for all color changes to take effect. I'm still working on a proper solution for this.
